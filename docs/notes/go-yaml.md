# go.yaml.in/yaml/v3

Конспект к шагу 8а (часть 3): YAML каталогов `bot/content/` (`drills.yaml`, `places.yaml`). Изучено 2026-11-16
по `go doc` и исходникам в кэше модулей (`$(go env GOMODCACHE)/go.yaml.in/yaml/v3@v3.0.6`).

## Версия

- `go.yaml.in/yaml/v3` **v3.0.6** (решение 2026-11-09): продолжение `gopkg.in/yaml.v3`, которое ведёт организация
  YAML (README: go-yaml/yaml автор пометил «unmaintained» в апреле 2025). В `go.mod` модуля — `go 1.16`.
- demoinfocs `v6.0.0-rc.1` держит в своём `go.mod` v3.0.5, но его пакеты YAML не импортируют
  (`grep` по исходникам). Наше требование v3.0.6 поднимает версию в графе модулей, на парсер это не влияет.

## Что используем

```go
dec := yaml.NewDecoder(bytes.NewReader(b))
dec.KnownFields(true)          // ключ, которого нет в структуре, — ошибка
if err := dec.Decode(&v); err != nil { ... }
var more any
if err := dec.Decode(&more); !errors.Is(err, io.EOF) { ... } // второй документ — ошибка
```

- `Unmarshal` читает только первый документ; `Decoder.Decode` — следующий и на конце возвращает `io.EOF`.
- Ключ, повторённый в одном отображении, — ошибка `*yaml.TypeError`: «line N: mapping key "x" already defined at
  line M» (`decode.go`, ~776). Разбор при этом идёт дальше, ошибка перечисляет все места.
- Теги полей — `yaml:"name,omitempty"`; без тега ключ — имя поля в нижнем регистре.
- `uint64`, `int`, `bool`, `map[string]T`, срезы и вложенные структуры разбираются как обычно; тип `findings.RuleID`
  (строка) — тоже.

## Подводные камни

- **Запятая во flow-записи** разделяет пары: `{ru: Т-сайд, верх, en: ...}` — это не строка «Т-сайд, верх». Такие
  значения — в кавычках.
- Двоеточие с пробелом внутри простого значения тоже ломает разбор — `title: Yprac Hub: префаеры` берём в кавычки.
- Длинные тексты — `>-` (сложенный блок): переносы строк становятся пробелами, перевода строки в конце нет.
- Кириллица — обычный UTF-8, кодировать не нужно.
- Комментарии (`# ...`) разбор не видит: в `places.yaml` ими помечены названия, которые нужно проверить игроку.

## Где используется

`bot/content/content.go`: `Parse` разбирает оба файла строго, затем проверяет каждое упражнение (оба языка,
одна ссылка, ошибки из `internal/findings`, мера и её направление) и каждую карту. Тест пакета проверяет каталоги,
встроенные в бинарник, и ошибки на испорченном YAML.
